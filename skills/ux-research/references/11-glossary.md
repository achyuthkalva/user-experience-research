# 11 — Keep the vocabulary stable

| Term | Meaning in this skill |
|---|---|
| OMSEP | Objective → Methodology → Scope → Essentials → Protocol; ordered research-planning phases |
| RQ | Research question linked to a decision; distinct from a participant-facing question |
| Research frame | Decision, goal, RQs, population, context, and relevant period |
| Tier | Source planning priority: 1 essential, 2 justify a cut after feasible alternatives, 3 may defer |
| Constraint disclosure | What was needed, selected method, constraint fit, supported/unsupported claims, limits, uncertainty, follow-up |
| Evidence category | Directional, patterned, sized, comparative, or business-case; source claim categories, not automatic certainty |
| Observation | Recorded action, statement, event, or artifact fact within its context |
| Reported behaviour | Participant's account of an action; not independent observation of the action |
| Observed behaviour | Action directly observed in a stated context; not automatically typical outside that context |
| Finding | Bounded factual result supported by traceable evidence |
| Insight | Interpretive explanation or implication; may remain a hypothesis |
| Hypothesis | An explanation or proposition to investigate, not an established fact |
| Say–do gap | Divergence between reported beliefs/accounts and observed behaviour; the source calls this a “confound” |
| Causal confounding | Mixing of influences that prevents attributing an outcome to the proposed cause; not the source's say–do shorthand |
| Unit of analysis | Entity being counted or analysed: person, session, task, ticket, organisation, etc. |
| Denominator | Defined eligible units with usable evidence for the stated metric; missing/unexposed units remain disclosed |
| Counterevidence | Evidence that challenges a finding, explanation, or proposed generalisation |
| Triangulation | Compare relevant sources/methods while assessing their independence and shared limitations |
| Severity | Prism's custom 1–5 assessment, with contextual rationale; not confidence or an approved roadmap |
| Priority | Proposed or approved action order after organisational trade-offs |
| H1 / H2 / H3 | Frame review / interpretation review / mandatory approval of a specific priority and action sequence |
| Pseudonymous ID | Project identifier replacing a direct identifier; does not guarantee anonymity |
| Native skill | Workflow installed and made available through a host's supported skill mechanism |
| Conversational attachment | File or text the user asks the assistant to follow within a conversation; not an automatic installation |
| `.skill` | In this release, a ZIP archive containing `ux-research/SKILL.md` and bundled text resources |
| Flat Chat edition | Generated, self-contained text containing the same instructions and references, without archive dependencies |
| Work / agent profile | Tool-aware execution adapted to actual permissions and capabilities |
| Chat profile | Conversation-first execution without assumptions of archive extraction, persistence, or agent tools |
| Team pilot | Usable release candidate with static checks; live platform and model evaluation still to be recorded |
